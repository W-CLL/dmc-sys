# 动态比例控制优化方案

## 问题背景

原有系统存在一个关键问题：**比例无限上升**

- 系统按照一个月的次数来判断是否需要添加操作
- 当比例超过200%时会自动添加操作次数
- 如果每天都添加，而客户的次数不增加，比例会持续上升
- 没有上限控制，可能导致比例过高被检测

## 解决方案

### 1. **动态比例计算算法**

#### 核心逻辑：
```php
// 设置最大比例限制（如400%）
if (当前比例 >= 最大比例) {
    return 0; // 停止添加
}

// 动态计算每日添加量
if (当前比例 >= 触发阈值) {
    // 使用动态算法计算添加量
    添加量 = min(
        基于最大比例的限制,
        基于目标比例的理想量,
        基于剩余空间的动态量
    );
} else {
    // 正常计算
    添加量 = 正常公式计算;
}
```

#### 动态调整策略：
- **距离上限越近，添加量越少**
- **保守系数控制**：不同类型任务有不同的保守程度
- **最小/最大限制**：确保添加量在合理范围内

### 2. **配置化管理**

创建了 `dynamic_ratio_config.php` 配置文件：

```php
'global' => [
    'max_percentage' => 400,        // 最大比例限制（400%）
    'trigger_percentage' => 200,    // 触发动态计算的比例（200%）
    'min_daily_add' => 5,          // 最小每日添加量
    'max_daily_add' => 20,         // 最大每日添加量
    'conservative_factor' => 1.0,   // 保守系数
],
```

### 3. **不同任务类型的差异化配置**

#### 全域推广任务：
- 最大比例：400%
- 每日添加：5-20个
- 保守系数：1.0（正常）

#### RPA任务：
- 最大比例：400%
- 每日添加：3-15个（更保守）
- 保守系数：0.8（更保守）

#### 标准推广任务：
- 最大比例：350%（更严格）
- 每日添加：3-12个
- 保守系数：0.9（稍保守）

## 核心算法详解

### 1. **动态添加量计算**

```php
// 计算剩余空间
$remainingPercentage = $maxPercentage - $currentPercentage;

// 计算最大可添加数量
$maxCanAdd = ($cusNum * $maxPercentage / 100) - $companyNum;

// 动态调整系数（距离上限越近，系数越小）
$percentageToMax = $remainingPercentage / ($maxPercentage - $triggerPercentage);
$dynamicDailyAdd = $minDailyAdd + ($maxDailyAdd - $minDailyAdd) * $percentageToMax;

// 选择最小值
$finalAddAmount = min($maxCanAdd, $idealAddAmount, $dynamicDailyAdd);
```

### 2. **安全机制**

- **紧急停止**：比例超过500%时完全停止
- **每日限制**：单个广告主每日最大操作次数
- **公司限制**：单个公司每日最大操作次数
- **详细日志**：记录所有计算过程

## 实际效果示例

### 场景1：正常情况
- 客户数：100，公司数：50，目标比例：30%
- 当前比例：50% < 60%（触发阈值）
- 计算：正常公式，添加约30个

### 场景2：接近触发阈值
- 客户数：100，公司数：120，目标比例：30%
- 当前比例：120% > 60%（触发阈值）
- 计算：动态算法，添加约10-15个

### 场景3：接近上限
- 客户数：100，公司数：350，目标比例：30%
- 当前比例：350% < 400%（最大限制）
- 计算：动态算法，添加约2-5个

### 场景4：达到上限
- 客户数：100，公司数：400，目标比例：30%
- 当前比例：400% = 400%（最大限制）
- 计算：停止添加，返回0

## 优势特点

### 1. **智能控制**
- 自动感知比例变化
- 动态调整添加策略
- 避免比例无限上升

### 2. **安全可靠**
- 多重安全机制
- 详细日志记录
- 紧急停止功能

### 3. **灵活配置**
- 不同任务类型差异化配置
- 特殊公司个性化设置
- 参数可动态调整

### 4. **向后兼容**

- 可随时回滚

## 监控建议

### 1. **关键指标监控**
- 各公司的当前比例
- 每日添加量统计

### 2. **告警机制**
- 比例超过350%时发出警告

### 3. **定期审查**

- 每月分析比例趋势
- 季度优化算法策略
