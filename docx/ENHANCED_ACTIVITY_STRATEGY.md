# 增强版活跃度保持策略

## 问题背景

原有的保底策略只在剩余空间>50%时才触发，这导致：
- 剩余空间20%-50%时：无操作，账户不活跃
- 剩余空间<20%时：无操作，账户不活跃
- 无法在接近上限时保持必要的活跃度

## 解决方案

### 🎯 **三层保底策略**

#### 1. **正常保底策略**（剩余空间 > 50%）
- **全域任务**：每50%空间 × 最小每日添加量
- **RPA任务**：每60%空间 × 最小每日添加量（更保守）

#### 2. **保守活跃度策略**（剩余空间 20%-50%）
- **全域任务**：每20%空间给2个操作
- **RPA任务**：每25%空间给1个操作（更保守）

#### 3. **最小活跃度策略**（剩余空间 0%-20%）
- **全域任务**：至少1个，每10%空间给1个操作
- **RPA任务**：至少1个，每15%空间给1个操作（更保守）

## 策略详解

### 全域任务策略：
```php
if ($remainingPercentage > 50) {
    // 正常保底：每50%空间 × 5个（最小每日添加量）
    $fallbackAmount = ceil($remainingPercentage / 50) * $minDailyAdd;
} elseif ($remainingPercentage > 20) {
    // 保守活跃：每20%空间给2个操作
    $fallbackAmount = ceil($remainingPercentage / 20) * 2;
} else {
    // 最小活跃：至少1个，每10%空间给1个操作
    $fallbackAmount = max(1, ceil($remainingPercentage / 10));
}
```

### RPA任务策略（更保守）：
```php
if ($remainingPercentage > 50) {
    // RPA正常保底：每60%空间 × 3个（更保守）
    $fallbackAmount = ceil($remainingPercentage / 60) * $minDailyAdd;
} elseif ($remainingPercentage > 20) {
    // RPA保守活跃：每25%空间给1个操作
    $fallbackAmount = ceil($remainingPercentage / 25) * 1;
} else {
    // RPA最小活跃：至少1个，每15%空间给1个操作
    $fallbackAmount = max(1, ceil($remainingPercentage / 15));
}
```

## 实际效果示例

```
策略：📊 正常保底策略（剩余空间充足）
```

### 场景2：剩余空间中等（35%）
```

策略：⚡ 保守活跃度策略（剩余空间中等）
```

### 场景3：剩余空间很少（8%）
```
全域任务：max(1, ceil(8 / 10)) = max(1, 1) = 1个
RPA任务：max(1, ceil(8 / 15)) = max(1, 1) = 1个
策略：🔥 最小活跃度策略（剩余空间很少）
```

### 场景4：剩余空间极少（2%）
```
全域任务：max(1, ceil(2 / 10)) = max(1, 1) = 1个
RPA任务：max(1, ceil(2 / 15)) = max(1, 1) = 1个
策略：🔥 最小活跃度策略（剩余空间很少）
```

## 策略优势

### 1. **全覆盖保护**
- 任何有剩余空间的情况都能保持活跃度
- 不再有"有空间却不操作"的情况
- 确保账户始终保持最基本的活跃度

### 2. **渐进式保守**
- 剩余空间越少，操作越保守
- 避免在接近上限时过度操作
- 平衡活跃度和安全性

### 3. **差异化处理**
- 全域任务相对积极
- RPA任务更加保守
- 符合不同任务类型的特点

### 4. **智能调试**
- 详细显示使用的策略类型
- 完整的计算过程记录
- 便于监控和优化

## 配置参数

### 可调整的关键参数：
```php
'fallback_strategy' => [
    'global' => [
        'high_space_threshold' => 50,    // 高空间阈值
        'medium_space_threshold' => 20,  // 中等空间阈值
        'high_space_divisor' => 50,      // 高空间除数
        'medium_space_divisor' => 20,    // 中等空间除数
        'low_space_divisor' => 10,       // 低空间除数
        'medium_space_multiplier' => 2,  // 中等空间倍数
    ],
    'rpa' => [
        // RPA更保守的参数设置
        'high_space_divisor' => 60,      // 更大的除数 = 更保守
        'medium_space_divisor' => 25,    // 更大的除数 = 更保守
        'low_space_divisor' => 15,       // 更大的除数 = 更保守
        'medium_space_multiplier' => 1,  // 更小的倍数 = 更保守
    ],
],
```

## 安全保障

### 1. **多重限制**
- 仍然受最大比例限制约束
- 仍然受动态每日限制约束
- 保底策略不会导致比例失控

### 2. **渐进式保守**
- 越接近上限越保守
- RPA任务比全域任务更保守
- 确保安全性

### 3. **可配置控制**
- 所有参数都可以通过配置文件调整
- 支持开关控制
- 可以随时优化策略
