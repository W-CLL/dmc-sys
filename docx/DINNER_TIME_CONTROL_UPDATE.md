# 晚饭时间控制功能更新

## 更新概述

根据用户需求，在原有午饭时间控制的基础上，新增了晚饭时间控制功能，实现了多时间段的饭点控制。

## 🍽️ **多饭点时间段支持**

### 原有功能：
- 只支持午饭时间（12:00-13:30）

### 更新后功能：
- **午饭时间**：12:00-13:30
- **晚饭时间**：18:00-19:30
- **可扩展**：支持添加更多时间段

## ⚙️ **配置更新**

### 新的配置结构：
```php
'meal_time_control' => [
    'enable' => true,                   // 总开关
    'description' => '在饭点时间降低任务执行频率，模拟人的行为',
    
    // 多时间段配置
    'time_periods' => [
        // 午饭时间
        'lunch' => [
            'name' => '午饭时间',
            'start_hour' => 12,         // 12:00开始
            'start_minute' => 0,
            'end_hour' => 13,           // 13:30结束
            'end_minute' => 30,
            'enabled' => true,          // 可单独启用/禁用
        ],
        // 晚饭时间
        'dinner' => [
            'name' => '晚饭时间',
            'start_hour' => 18,         // 18:00开始
            'start_minute' => 0,
            'end_hour' => 19,           // 19:30结束
            'end_minute' => 30,
            'enabled' => true,          // 可单独启用/禁用
        ],
    ],
    
    // 统一的控制参数（适用于所有饭点时间）
    'max_tasks_per_minute' => 2,        // 每分钟最多2个任务
    'extra_delay_seconds' => 30,        // 额外延时30秒
    'skip_probability' => 70,           // 70%概率跳过执行
    'min_skip_delay' => 300,            // 跳过时最小延时5分钟
    'max_skip_delay' => 900,            // 跳过时最大延时15分钟
],
```

## 🕐 **时间段检测逻辑**

### 智能时间检测（支持跨天时间段）：
```php
function getCurrentMealPeriod() {
    $currentTime = 当前小时 * 60 + 当前分钟;

    foreach (所有时间段) {
        if (!时间段启用) continue;

        $startTime = 开始小时 * 60 + 开始分钟;
        $endTime = 结束小时 * 60 + 结束分钟;

        if ($endTime < $startTime) {
            // 跨天时间段：如23:30-01:30
            if ($currentTime >= $startTime || $currentTime <= $endTime) {
                return 时间段信息;
            }
        } else {
            // 同一天时间段：如12:00-13:30
            if ($currentTime >= $startTime && $currentTime <= $endTime) {
                return 时间段信息;
            }
        }
    }

    return null; // 不在任何饭点时间
}
```

### 跨天时间段示例：
```
宵夜时间：23:30-01:30
- 23:30-23:59 ✅ 检测到（今天晚上）
- 00:00-01:30 ✅ 检测到（明天凌晨）
- 01:31-23:29 ❌ 不在时间段内
```

### 支持的时间段：
- **午饭时间**：12:00-13:30（720-810分钟）
- **晚饭时间**：18:00-19:30（1080-1170分钟）
- **其他时间**：正常执行

## 🔧 **灵活配置选项**

### 1. **单独控制每个时间段**
```php
// 只启用午饭时间控制
'lunch' => ['enabled' => true],
'dinner' => ['enabled' => false],

// 只启用晚饭时间控制
'lunch' => ['enabled' => false],
'dinner' => ['enabled' => true],
```

### 2. **调整时间范围**
```php
// 延长晚饭时间到20:00
'dinner' => [
    'start_hour' => 18,
    'end_hour' => 20,
    'end_minute' => 0,
],

// 缩短午饭时间到13:00
'lunch' => [
    'start_hour' => 12,
    'end_hour' => 13,
    'end_minute' => 0,
],
```

### 3. **添加更多时间段**
```php
// 添加夜宵时间（跨天时间段）
'night_snack' => [
    'name' => '夜宵时间',
    'start_hour' => 23,         // 23:30开始
    'start_minute' => 30,
    'end_hour' => 1,            // 01:30结束（第二天）
    'end_minute' => 30,
    'enabled' => true,
],
```

## 🎯 **行为模拟效果**

### 模拟真实用户一天的操作模式：
1. **上午**：正常工作，操作频率正常
2. **午饭时间**：大部分时间在吃饭，偶尔操作
3. **下午**：正常工作，操作频率正常
4. **晚饭时间**：大部分时间在吃饭，偶尔操作
5. **晚上**：正常工作，操作频率正常

### 对比效果：
- **优化前**：全天24小时执行频率一致
- **优化后**：饭点时间执行频率显著降低，更符合人的作息

## ⚠️ **注意事项**

### 1. **执行进度影响**
- 增加晚饭时间控制后，整体执行速度会进一步降低
- 需要平衡隐蔽性和执行效率
- 可能需要调整总体任务计划

### 2. **时间设置合理性**
- 饭点时间设置要符合目标用户群体的作息
- 考虑不同地区的饮食习惯差异
- 可以根据实际情况调整时间范围

### 3. **系统资源**
- 多时间段控制会增加系统复杂度
- 需要监控Redis缓存的使用情况
- 注意日志文件的大小增长

## 🚀 **扩展建议**

- 可以根据历史数据自动调整时间范围

通过这次更新，系统现在支持午饭和晚饭两个时间段的控制，更好地模拟了真实用户的一天作息规律，进一步提升了操作的隐蔽性和自然性。
