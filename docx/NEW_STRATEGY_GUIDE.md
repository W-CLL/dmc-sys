# 新分层控制策略指南

## 策略概述

根据用户需求，实现了全新的分层控制策略，更精确地控制不同比例范围内的操作行为。

## 🎯 **策略分层**

### 1. **< 200%：正常追加**
- **行为**：按照目标比例正常计算追加量
- **公式**：`实际需要数 = 客户数 + (客户数 × 目标比例 / 100)`
- **日志**：`✅ 广告主 XXX 比例正常（XX%），正常追加 XX 次`

### 2. **200%-400%：检查操作空间**
- **行为**：检查到600%的剩余操作空间
- **条件**：如果操作空间 ≤ 10%（可配置），则停止操作
- **条件**：如果操作空间 > 10%，则进行动态计算
- **日志**：
  - 空间不足：`⚠️ 广告主 XXX 操作空间不足10%（剩余X%），停止操作`
  - 空间充足：进入动态计算流程

### 3. **400%-600%：保持活跃度**
- **行为**：只进行最小活跃度操作，不再追加
- **操作次数**：1-20次随机（全域），1-15次随机（RPA）
- **日志**：`🔄 广告主 XXX 比例400%-600%（当前XX%），保持活跃度 X 次`

### 4. **> 600%：完全停止**
- **行为**：完全停止操作，返回0
- **日志**：`🚫 广告主 XXX 比例超过600%（当前XX%），完全停止操作`

## 📊 **配置参数**

### 新策略配置：
```php
'new_strategy' => [
    'normal_threshold' => 200,          // 正常追加阈值（%）
    'dynamic_threshold' => 400,         // 动态计算阈值（%）
    'activity_threshold' => 600,        // 活跃度阈值（%）
    'min_space_threshold' => 10,        // 最小操作空间阈值（%）
    'enable' => true,                   // 是否启用新策略
],
```

### 可调整参数说明：
- **normal_threshold**：正常追加的上限比例
- **dynamic_threshold**：开始只保持活跃度的比例
- **activity_threshold**：完全停止操作的比例
- **min_space_threshold**：最小操作空间要求

## 🔄 **RPA任务差异化**

RPA任务采用更保守的策略：

### 操作空间阈值：
- **全域任务**：10%
- **RPA任务**：15%（10% + 5%，更保守）

### 活跃度操作：
- **全域任务**：1-20次
- **RPA任务**：1-15次（更保守）

## 🎛️ **操作空间计算**

### 计算公式：
```php
$operatingSpace = $activityThreshold - $currentPercentage;
// 操作空间 = 600% - 当前比例
```

### 示例：
- 当前比例：390%
- 操作空间：600% - 390% = 210%
- 判断：210% > 10%，可以操作

- 当前比例：595%
- 操作空间：600% - 595% = 5%
- 判断：5% ≤ 10%，停止操作

## 🔧 **策略优势**

### 1. **精确控制**
- 四个明确的比例区间
- 每个区间有不同的处理策略
- 可配置的阈值参数

### 2. **安全保障**
- 600%硬上限，绝不超过
- 操作空间预警机制
- 渐进式保守策略

### 3. **活跃度保持**
- 400%-600%区间仍保持活跃度
- 避免账户被标记为不活跃
- 智能的活跃度操作次数

### 4. **差异化处理**
- RPA任务更保守的参数
- 全域任务相对积极
- 符合不同任务特点
