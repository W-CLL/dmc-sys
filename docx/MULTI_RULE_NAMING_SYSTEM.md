# 多规则循环命名系统

## 功能概述

实现了一个全新的计划名称修改系统，支持多种修改规则的循环使用，达到"第一次修改，第二次还原，每次修改规则不同"的效果。

## 🎯 **核心特性**

### 1. **多规则循环**
- 支持5种不同的修改规则
- 每次修改使用不同的规则
- 自动循环切换规则

### 2. **修改-还原循环**
- 第一次：应用规则修改名称
- 第二次：还原到原始名称
- 第三次：使用下一个规则修改
- 第四次：再次还原
- 循环往复...

### 3. **智能检测**
- 自动检测名称是否已被修改
- 根据检测结果决定修改或还原
- 支持不同规则的模式匹配

## 📋 **五种修改规则**

### 1. **时间戳标记**
```
原名称：智能推广计划
修改后：智能推广计划(.0115_143025.)
还原后：智能推广计划
```
- **格式**：`(.月日_时分秒.)`
- **示例**：`(.0115_143025.)`
- **特点**：精确到秒，唯一性强

### 2. **序号标记**
```
原名称：智能推广计划
修改后：智能推广计划[1]
还原后：智能推广计划
```
- **格式**：`[序号]`
- **示例**：`[1]`, `[2]`, `[3]`
- **特点**：递增序号，简洁明了

### 3. **字母标记**
```
原名称：智能推广计划
修改后：智能推广计划{A}
还原后：智能推广计划
```
- **格式**：`{字母}`
- **示例**：`{A}`, `{B}`, `{AB}`
- **特点**：随机字母组合

### 4. **下划线标记**
```
原名称：智能推广计划
修改后：智能推广计划_new
还原后：智能推广计划
```
- **格式**：`_单词`
- **示例**：`_new`, `_opt`, `_pro`, `_adv`
- **特点**：常见后缀，自然美观

### 5. **点号标记**
```
原名称：智能推广计划
修改后：智能推广计划...
还原后：智能推广计划
```
- **格式**：`.` (2-5个)
- **示例**：`..`, `...`, `....`
- **特点**：简单低调，不显眼

## 🔄 **规则循环示例**

### 完整的循环过程：
```
第1次执行：智能推广计划 → 智能推广计划(.0115_143025.) [时间戳规则]
第2次执行：智能推广计划(.0115_143025.) → 智能推广计划 [还原]
第3次执行：智能推广计划 → 智能推广计划[1] [序号规则]
第4次执行：智能推广计划[1] → 智能推广计划 [还原]
第5次执行：智能推广计划 → 智能推广计划{A} [字母规则]
第6次执行：智能推广计划{A} → 智能推广计划 [还原]
第7次执行：智能推广计划 → 智能推广计划_new [下划线规则]
第8次执行：智能推广计划_new → 智能推广计划 [还原]
第9次执行：智能推广计划 → 智能推广计划... [点号规则]
第10次执行：智能推广计划... → 智能推广计划 [还原]
第11次执行：智能推广计划 → 智能推广计划(.0115_150030.) [回到时间戳规则]
...循环往复
```

## 🎛️ **技术实现**

### 1. **NameRuleManager类**
- 管理所有修改规则
- 跟踪当前使用的规则
- 提供规则切换功能

### 2. **规则检测**
```php
// 检查名称是否已被修改
list($isModified, $matchedRuleKey, $matchedContent) = NameRuleManager::checkNameModified($originalName);
```

### 3. **规则应用**
```php
if ($isModified) {
    // 还原名称
    $restoredName = NameRuleManager::restoreName($originalName, $currentRule['rule']);
} else {
    // 修改名称
    $modifiedName = NameRuleManager::generateModifiedName($originalName, $currentRule, $advId, $objId);
}
```

### 4. **规则切换**
```php
// 更新到下一个规则
NameRuleManager::updateRuleIndex($advId, $objId);
```

## 📊 **三种Job类型的差异**

### 标准推广（BaseUpdateStandJob）：
```
【标准推广】修改计划名称: 原名称 -> 新名称 (使用规则: 时间戳标记)
【标准推广】还原计划名称: 新名称 -> 原名称 (使用规则: 时间戳标记)
```

### 全域推广（BaseUpdateGlobalJob）：
```
【全域推广】修改计划名称: 原名称 -> 新名称 (使用规则: 序号标记)
【全域推广】还原计划名称: 新名称 -> 原名称 (使用规则: 序号标记)
```

### RPA任务（BaseUpdateWebJob）：
```
【RPA任务】修改计划名称: 原名称 -> 新名称 (使用规则: 字母标记)
【RPA任务】还原计划名称: 新名称 -> 原名称 (使用规则: 字母标记)
```

## 🗄️ **缓存管理**

### 规则索引缓存：
- **键名**：`name_rule_{广告主ID}_{计划ID}`
- **值**：当前规则索引
- **过期时间**：7天

### 序号缓存：
- **键名**：`sequence_{广告主ID}_{计划ID}`
- **值**：当前序号
- **过期时间**：1天
