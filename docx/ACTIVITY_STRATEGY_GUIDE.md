# 账户活跃度保持策略

## 策略背景

即使广告账户达到了设置的最大比例限制（如400%），也需要保持一定的活跃度，避免账户因为完全停止操作而被平台标记为异常或不活跃。

## 核心策略

### 1. **最小活跃度机制**

当账户比例达到最大限制时：
- **不再停止操作**：避免返回0次操作
- **保持最小活跃度**：每天至少操作1-20次
- **随机化处理**：操作次数在范围内随机，避免规律性

### 2. **差异化配置**

#### 全域推广任务：
```php
'min_active_operations' => 1,   // 最小1次
'max_active_operations' => 20,  // 最大20次
```

#### RPA任务：
```php
'min_active_operations' => 1,   // 最小1次
'max_active_operations' => 15,  // 最大15次（更保守）
```

#### 标准推广任务：
```php
'min_active_operations' => 1,   // 最小1次
'max_active_operations' => 12,  // 最大12次（最保守）
```

### 3. **智能时间调整**

#### 工作时间（9:00-18:00）：
- **稍微增加活跃度**：+1到+3次操作
- **模拟正常工作时间的活跃度**

#### 深夜时间（22:00-06:00）：
- **减少活跃度**：-1到-3次操作
- **符合深夜较少操作的自然规律**

#### 其他时间：
- **保持基础活跃度**：按配置范围随机

## 实际效果示例

### 场景1：全域推广达到上限
```
当前比例：420% > 400%（最大限制）
原策略：返回0次操作 ❌
新策略：返回5-18次操作 ✅
时间调整：工作时间可能+2次，深夜可能-1次
```

### 场景2：RPA任务达到上限
```
当前比例：410% > 400%（最大限制）
原策略：返回0次操作 ❌
新策略：返回3-12次操作 ✅（比全域保守）
时间调整：工作时间可能+1次，深夜可能-2次
```

### 场景3：标准推广达到上限
```
当前比例：360% > 350%（最大限制）
原策略：返回0次操作 ❌
新策略：返回2-10次操作 ✅（最保守）
时间调整：工作时间可能+1次，深夜可能-1次
```

## 配置参数说明

### 活跃度策略配置：
```php
'activity_strategy' => [
    'enable_min_activity' => true,     // 启用最小活跃度策略
    'random_factor' => true,           // 使用随机因子
    'time_based_adjustment' => true,   // 基于时间调整
],
```

### 调试配置：
```php
'debug' => [
    'log_activity_operations' => true, // 记录活跃度操作
    'enable_logging' => true,          // 启用详细日志
],
```

## 优势特点

### 1. **避免账户异常**
- 防止账户因完全停止操作被标记
- 保持自然的操作频率
- 符合正常用户行为模式

### 2. **智能化调整**
- 基于时间的智能调整
- 不同任务类型差异化处理
- 随机化避免规律性

### 3. **可控性强**
- 配置化管理，可随时调整
- 支持开关控制
- 详细日志记录

### 4. **安全性高**
- 活跃度操作次数有上限
- 不会无限增加比例
- 保持在合理范围内

## 监控建议

### 1. **活跃度监控**
- 监控达到上限的账户数量
- 统计活跃度操作的分布
- 观察账户状态变化

### 2. **效果评估**
- 对比启用前后的账户状态
- 监控平台对账户的反馈
- 评估活跃度策略的有效性

### 3. **参数优化**
- 根据实际效果调整活跃度范围
- 优化时间调整策略
- 完善不同任务类型的配置

## 风险控制

### 1. **上限控制**
- 活跃度操作有明确上限
- 不会导致比例进一步上升
- 保持在安全范围内

### 2. **开关控制**
- 可通过配置随时关闭
- 支持紧急情况下的快速调整
- 保留原有逻辑作为备选

### 3. **监控告警**
- 异常情况及时告警
- 活跃度操作过多时提醒
- 定期审查策略效果

## 使用建议

### 1. **初期部署**
- 先在少量账户上测试
- 观察平台反应
- 逐步扩大应用范围

### 2. **参数调优**
- 根据实际情况调整活跃度范围
- 优化时间调整策略
- 完善不同场景的配置

### 3. **持续监控**
- 定期检查活跃度效果
- 监控账户状态变化
- 及时调整策略参数

通过这套活跃度保持策略，可以确保即使在达到比例上限的情况下，账户仍然保持适度的活跃度，避免被平台识别为异常账户，同时不会进一步推高比例。
